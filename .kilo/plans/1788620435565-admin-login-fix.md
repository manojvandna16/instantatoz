# Plan: Fix Admin Login 401 Error

## Problem
Admin login at `instantatoz.vercel.app` fails with repeated `401` errors on `/api/auth/session`. The Vercel production deployment is missing Firebase Admin SDK environment variables.

## Root Cause
`apps/admin/.env.vercel` only contains `VERCEL_OIDC_TOKEN`. It is missing the three required Firebase Admin credentials:
- `FIREBASE_PROJECT_ID`
- `FIREBASE_CLIENT_EMAIL`
- `FIREBASE_PRIVATE_KEY`

Without these, `getAdminApp()` in `apps/admin/lib/firebase-admin.ts:22-24` throws at initialization, and the `/api/auth/session` route returns a generic 401.

Additionally, `apps/admin/lib/auth-context.tsx:76-80` does not check the response from `/api/auth/session`. If session creation fails, the error is silently swallowed and the page redirects to `/dashboard`, where `proxy.ts` redirects back to `/`.
